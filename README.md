## Site Tocar Junto

The static site is published with GitHub Pages from the `main` branch, repository root. Its entry page is `index.html`; the `course_catalog_artifacts/` directory contains the images referenced by the page.

To enable or verify publishing, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save. GitHub Pages sites are publicly accessible.
